第 1 步安装 Java 运行时

  
Minecraft 服务端是 Java 程序，必须先有 Java 才能运行。选错版本会直接报 UnsupportedClassVersionError。


  
为什么要指定版本
    每个 Minecraft 版本编译时用的 Java 版本不同，只能高不能低：
    
    
      
  • MC 1.20.5 ~ 1.21.x → 需要 Java 21
    • 
      
  • MC 26.x 及以后 → 需要 Java 25
    • 
      
  • MC 1.17 ~ 1.20.4 → 需要 Java 17
    • 
      
  • MC 1.16.5 及更早 → 需要 Java 8
    • 
    

    当前选择：Java 21

openjdk version "21.0.12" 2026-08-18
OpenJDK 64-Bit Server VM (build 21.0.12, mixed mode)

  


  
❌ 常见错误

server.properties 关键参数详解

  

    
参数作用建议

    
      
server-port监听端口，默认 25565（TCP）保持 25565，冲突再改

      
online-mode是否验证正版账号公网必须 true；false 时任何人可冒充

      
view-distance玩家视野距离（区块）设备弱设 4~6，最影响性能的一项

      
simulation-distance实体/红石模拟距离设 4~6，比视野更吃 CPU

      
max-players最大同时在线人数按内存设，别超过硬件承受能力

      
motd服务器列表里显示的名字随意写，支持颜色代码

      
spawn-protection出生点保护半径自己玩设 0，公开服设 16

      
difficulty难度 peaceful/easy/normal/hard默认 easy

      
white-list是否只允许白名单进入公开服建议 true

      
enable-command-block是否允许命令方块地图/玩法需要就 true

JVM 启动参数逐项说明

  

    
参数含义

    
      
-Xms / -Xmx堆内存初始值 / 最大值。两者设成一样，避免运行中反复扩容

      
-XX:+UseG1GC使用 G1 垃圾回收器，Minecraft 官方推荐

      
-XX:MaxGCPauseMillis单次 GC 最长停顿目标，越小越不卡但更耗 CPU

      
-XX:+AlwaysPreTouch启动时预先占满内存，减少运行中抖动

      
-XX:+ParallelRefProcEnabled并行处理引用，降低 GC 停顿（Aikar 方案核心项）

      
-XX:G1NewSizePercent 等新一代堆占比，调优后能让 TPS 更稳

      
-Dusing.aikars.flags标记来源，仅用于提示；参数本身来自 Aikar 调优方案

    
  


  
✅ 成功标志

怎么安全地关服

  
不要直接关窗口
    强行关掉进程可能导致世界文件损坏。正确做法是在服务器控制台输入 stop 再回车，
    等日志出现 ThreadedAnvilChunkStorage: All chunks are saved 后再结束。
    服务器窗口里执行 Ctrl+C 是次选，也可触发保存。

第 6 步日常运维


  
mcctl —— 服务器管理工具（部署时自动装上）

    部署完成后服务器目录里会有一个 mcctl，开服关服看状态一个脚本全包，
    不需要 tmux 或 screen：它用 FIFO 接管服务端标准输入，所以关服是优雅的（会存档）。
    
./mcctl start      后台开服（Termux 下自动加唤醒锁）
./mcctl stop       优雅关服，自动存档
./mcctl restart    重启
./mcctl status     状态面板：运行时长 / 内存 / 端口 / 世界大小 / 最新日志
./mcctl logs       实时日志
./mcctl cmd list   向服务器发指令（list / op 名字 / whitelist add 名字…）
./mcctl backup     备份世界到 ~/mc-backups，自动保留最近 7 份
./mcctl port       显示当前端口并检查占用
./mcctl freeport   静默探测一个空闲端口

    Termux 上的额外照顾：start 时会自动执行 termux-wake-lock
    （防止息屏后服务被系统挂起），装了 termux-api 的话还会在通知栏挂一条常驻状态。
  


  
备份世界（最重要的一件事）

    手动备份：先停服，再打包这三个目录。

    cd ~/mc && tar czf ~/backup-$(date +%F-%H%M).tar.gz world world_nether world_the_end


    自动备份脚本：存成 backup.sh，用 crontab -e 每天跑一次。
    
#!/usr/bin/env bash
# 保留最近 7 份备份，自动删旧的
cd "$HOME/mc" || exit 1
mkdir -p "$HOME/mc-backups"
tar czf "$HOME/mc-backups/world-$(date +%F-%H%M).tar.gz" world world_nether world_the_end
ls -1t "$HOME/mc-backups"/world-*.tar.gz | tail -n +8 | xargs -r rm -f
echo "备份完成: $(ls -1 "$HOME/mc-backups" | wc -l) 份"

    恢复：tar xzf 备份文件.tar.gz，覆盖回服务器目录即可。

    强烈建议用 rsync 或网盘把备份同步到另一台设备，避免设备损坏导致全丢。
  


  
更新服务端到新版本

    Paper / Vanilla / Fabric：停服 → 删掉旧的 server.jar（不要删 world 目录）→
    重新执行第 2 步的下载命令 → 启动。

    Forge / NeoForge：换掉 installer.jar，重新执行
    java -jar installer.jar --installServer，再启动。

    注意：不能任意跨大版本降级世界（如 1.21 存档放回 1.20 会损坏）。
    升级前务必先备份，并确认插件/模组都支持新版本。
  


  
安装插件（仅 Paper 等支持）

    停服后把插件的 .jar 放进 plugins/ 目录，重启即可。

    常用插件：EssentialsX（基础指令）、LuckPerms（权限）、
    CoreProtect（防破坏与回滚）、WorldEdit（建筑编辑）。

    来源可信很重要：只从插件官网或 Modrinth / Hangar / SpigotMC 下载，
    来路不明的插件常带后门。
  


  
模组与加载器对应关系

    Fabric：轻量、更新快，模组文件放 mods/，需要 Fabric API。

    NeoForge：1.20.2 之后的主流，新整合包多用它。

    Forge：老版本模组最全，1.20.1 及以前首选。

    重要：客户端和服务端的模组必须匹配；只装客户端模组（如小地图、优化光影）会导致进不去。
  


  
管理员与白名单

    在服务器控制台（不是聊天框）输入：

    op 你的游戏ID — 给自己管理员权限

    whitelist on — 开启白名单

    whitelist add 好友ID — 允许某人进入

    whitelist list / whitelist remove 名字 — 查看 / 移除

    ban 名字 / kick 名字 — 封禁 / 踢出


    开白名单前记得把自己的 ID 加进去，否则会被锁在外面。
  


  
查看日志与性能

    logs/latest.log 是当前日志，logs/ 里按日期存档旧日志。

    游戏内输入 /tps（Paper）看服务器帧率，持续低于 19 说明负载偏高。

    卡顿时优先降低 view-distance 和 simulation-distance，
    再考虑减少实体、限制红石机械、给世界做预生成。
  







  
排错报错信息对照表

  
在日志或终端里搜关键字，按下表处理。

  

    
报错关键字原因解决

    
      
UnsupportedClassVersionErrorJava 版本低于该 MC 版本要求按第 1 步表格装对应 Java

      
CANNOT LINK EXECUTABLE "curl"
cannot locate symbol "SSL_set_quic_tls_early_data_enabled"		
        Termux 的 libcurl 与 openssl 版本不同步。多见于单独执行 pkg install curl，
          libcurl 升级了而 openssl 没跟上
        ① 先直接重跑，常常只是升级过程中的瞬时状态，几秒后自愈

          ② 仍不行：pkg upgrade -y

          ③ 若 pkg 也报同样错误（apt 同样依赖 libcurl），用手机浏览器到
          packages.termux.dev/apt/termux-main/pool/main/o/openssl/
          下载带 aarch64 的包，再 dpkg -i /sdcard/Download/openssl_*_aarch64.deb

      
Unable to access jarfile文件名写错或不在当前目录用 ls 看实际文件名，再改命令

      
You need to agree to the EULA没同意协议echo "eula=true" > eula.txt

      
Address already in use端口被占用（常是上次没关干净）pkill -f server.jar 或换个端口

      
Failed to bind to port端口被占用或权限不足用 1024 以上端口；查是否已有实例在跑

      
OutOfMemoryError堆内存分配过小或物理内存不足调大 -Xmx，或减少玩家/视距

      
进程被 Killed 且无日志被系统 OOM 杀掉或后台限制回收降低 -Xmx、减少后台程序、关闭电源优化

      
java.lang.OutOfMemoryError: Metaspace模组过多加 -XX:MaxMetaspaceSize=512M

      
zip END header not found / 不是有效 jar下载不完整或被拦成 HTML重新下载并校验哈希

      
Connection refused / timed out端口不通或防火墙先在服务器本机用 localhost 连；再查网络

      
Unsupported major.minor version同上，Java 太低升级 Java

      
Permission denied文件没有执行权限 / 目录属主不对chmod +x start.sh，或修正目录属主

Termux 使用速成（没用过命令行必看）

    安装：从 F-Droid 安装 Termux，不要用 Google Play 版（版本陈旧且仓库地址失效）。

    回车：软键盘上的回车键。

    中断当前命令：按 音量减 + C（屏幕上会出现 Ctrl，再按 C）。

    常用操作：ls 看文件、cd 目录 进入、
    pwd 看当前位置、cat 文件 看内容、nano 文件 编辑（Ctrl+O 保存，Ctrl+X 退出）。
  


  
安装 Java 慢？换国内源

    Termux 换源（最省事）：执行 termux-change-repo，
    在界面里选 Mirror group → China → TUNA，然后重新 pkg update。


    Ubuntu / Debian 系换源：先备份，再替换。
    
cp /etc/apt/sources.list /etc/apt/sources.list.bak
sed -i 's@//ports.ubuntu.com@//mirrors.tuna.tsinghua.edu.cn/ubuntu-ports@g' /etc/apt/sources.list
apt-get update

    x86 机器用的是 archive.ubuntu.com，把上面 ports.ubuntu.com 换成
    archive.ubuntu.com、镜像路径换成 /ubuntu 即可。
  


  
内网穿透方案对比

    为什么要穿透：家用宽带和移动网络通常没有公网 IP，外网无法直接连到你的 25565 端口。


    playit.gg — 免费额度够朋友联机，有 arm64/x64 Linux 客户端，注册后给一个固定域名，配置最简单。

    frp / nginx 反代 — 需要一台有公网 IP 的云服务器，最稳定可控，适合长期开服。

    商业内网穿透面板 — 如 Sakura Frp、花生壳，图形界面友好，免费版带宽和隧道数有限。

    路由器端口映射 — 仅当运营商给了公网 IP 时可行，在路由器里把外部 25565 映射到内网设备。


    安全提醒：暴露到公网时务必保持 online-mode=true 并启用白名单，
    否则容易被扫描到并遭受破坏或攻击。
  


  
术语表

    服务端 / 客户端 — 服务端是长期运行、保存世界的那一方；客户端是你用来玩的游戏本体。

    插件（Plugin） — 只在 Paper/Spigot 类服务端运行，玩家客户端不需要装，用于权限、经济、保护等。

    模组（Mod） — 通过 Fabric/Forge/NeoForge 加载，通常客户端也要装同样的，用于增加游戏内容。

    TPS — 每秒游戏刻数，正常 20；低于 20 表示服务器跟不上，表现为卡顿、怪物瞬移。

    区块（Chunk） — 16×16 的地图单位，加载和保存都以区块为单位，是性能主要瓶颈。

    正版验证 — 向 Mojang 验证登录账号真伪，关闭后任何人都能冒用他人 ID 进入。

    JVM / 堆内存 — Java 虚拟机及其可用内存上限，即 -Xmx 控制的量。
